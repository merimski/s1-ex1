# 🎉 אירועים חינם בישראל

אפליקציית ווב בעברית (מימין לשמאל) שמציגה אירועים חינמיים ברחבי הארץ.

## יכולות
- חיפוש חופשי לפי שם, עיר או מקום
- סינון לפי אזור, קטגוריה, תאריך (היום / סוף השבוע / שבוע / חודש) ואירועים שמתאימים לילדים
- קישור למפה והוספה ליומן (קובץ ‎.ics) לכל אירוע
- הוספת אירועים משלכם (נשמרים בדפדפן)
- מצב כהה אוטומטי ותצוגה מותאמת לנייד

## הרצה
לא צריך התקנה. פשוט פותחים את `index.html` בדפדפן.

אפשר גם להריץ שרת מקומי:
```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

## נתונים
האירועים בקובץ `events.js` הם **נתוני דוגמה**. כדי להציג אירועים אמיתיים, מחליפים את הרשימה `window.EVENTS`
באירועים עם שדה `date` בפורמט `YYYY-MM-DD` (במקום `daysFromNow`):

```js
{ title: "שם האירוע", description: "תיאור", date: "2026-11-01", time: "19:00",
  city: "תל אביב-יפו", venue: "פארק הירקון", region: "מרכז", category: "מוזיקה",
  kids: true, link: "https://..." }
```

## קבצים
| קובץ | תפקיד |
|------|-------|
| `index.html` | מבנה העמוד |
| `styles.css` | עיצוב |
| `events.js` | נתוני האירועים, האזורים והקטגוריות |
| `app.js` | לוגיקת הסינון וההצגה |
